# Documentation Images

This directory contains visual assets used in Linguist documentation, including:

- Screenshots
- Diagrams
- Illustrations
- Animated demonstrations (GIFs)

## Usage

To reference an image in documentation, use relative paths:

```markdown
![Alt text](images/example.png)
```

## File Naming Convention

Use descriptive, lowercase names with underscores:
- `feature_screenshot.png`
- `workflow_diagram.svg`
- `chat_agent.gif`

## Supported Formats

- PNG for screenshots
- SVG for diagrams and icons
- GIF for animated demonstrations
- JPEG for photographs
